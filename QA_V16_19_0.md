## Required real-device regression
Before production deployment, test at minimum:
1. Create schema-3 Full Backup and confirm downloaded JSON exists.
2. Use **Verify backup file** on that exact file; expect full verification.
3. Copy the file to an actual off-device location; record the off-device receipt.
4. Modify a copy of the backup JSON and confirm whole-file verification reports mismatch.
5. Restore the unmodified backup in a disposable/test browser profile.
6. Confirm post-restore verification reports `full` and the app restarts into the restored dataset.
7. Force-close/reopen after Restore.
8. Rollback last Restore in a test profile and confirm pre-restore data returns.
9. Open a schema-2 backup and confirm it is treated as legacy/partial rather than full-manifest verified.
10. Final Lock → Archive VERIFIED → Full Backup → external copy → Verify File → Restore test.
11. Repeat offline where practical for local backup creation/verification.
12. Repeat on the actual Android PWA and Windows/iPad profiles used by the hospital.
