## Real ANESVET DOM layout test
The real V15.19 `index.html` DOM and real CSS files were loaded in a synthetic Chromium document with only the new disclosure module active.

Validated:
- 11/11 Settings panels enhanced and collapsed by default
- Drug long-reference panels collapsed by default: 3/3
- Recovery Handoff collapsed by default
- Recovery vital history collapsed by default
- Recovery Readiness Score remains open
- No horizontal overflow at phone/iPad/desktop viewports

Approximate synthetic Settings document-height reduction:
- 390×844: 7260 px → 2417 px
- 1024×768: 3620 px → 1468 px
- 1440×900: 3654 px → 1476 px

These height values are synthetic QA measurements, not a promise of exact production-page height.

## Environment limitation
A full local HTTP browser E2E could not be run because Chromium navigation to localhost is blocked by the execution environment (`ERR_BLOCKED_BY_ADMINISTRATOR`). Therefore this release does not claim full hardware/browser E2E on iPhone/iPad/Android. Pilot testing on real devices remains required.
