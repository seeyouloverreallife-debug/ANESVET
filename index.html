      Pre-OR Anesthesia Briefingสรุปความเสี่ยงและของที่ควรเตรียมก่อนเข้า OR
      
        
      หลังข้อมูลก่อนวางยาครบ ระบบจะสรุป key risks, medication plan และค่าเตรียมเบื้องต้น เช่น ETT working range, ventilation/O₂/fluid reference ตามข้อมูลที่มี
      ค่าบน Briefing เป็น preparation reference ไม่ใช่คำสั่งรักษา ต้องยืนยันกับ anatomy, monitor, anesthetic depth, physiology และ clinical judgment จริงก่อนใช้ และค่าจาก briefing จะไม่ถูกคัดลอกเป็น actual record อัตโนมัติ
      
      
      

      
      
        5
      OR LIVEVitals-first • Next Step • MORE ตาม phase
      
        
      ระหว่างวางยาให้ใช้ VITALS / RECORD NOW เป็นงานหลัก ใช้ NEXT STEP เมื่อต้องการเปลี่ยน milestone/phase และใช้ MORE สำหรับยา, airway, fluid/blood หรือ event/problem ตามบริบท
      การเปลี่ยน phase มี confirm/undo guard และระบบจะเก็บ timeline/audit เพื่อให้แก้การกดพลาดได้โดยไม่ลบประวัติ
      
      
      

      
      
        6
      RecoveryRecord → reassess → handoff
      
        
      ติดตาม airway, oxygenation, temperature, comfort และ mentation ต่อเนื่อง ใช้ Recovery vitals, readiness score และ problem tracking จน criteria ของโรงพยาบาล/สัตวแพทย์ผู้รับผิดชอบครบ
      Recovery 2.0 เพิ่ม structured pain/comfort, dysphoria, nausea/vomiting, mobility, trend summary, post-anesthetic medication review และ transfer handoff โดยเป็น documentation aid และไม่เพิ่ม discharge criterion อัตโนมัติ
      Emergency return to OR LIVE จะบันทึก workflow transition ไว้ และ Recovery complete ต้องผ่าน readiness review เดิมหรือมี documented override
