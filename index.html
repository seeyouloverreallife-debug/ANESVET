Hypotension

  1. Verify BP + pulse/perfusion
  2. Assess anesthetic depth → ลด inhalant ถ้าลึก
  3. Optimize analgesia / local block
  4. ถามว่า volume, HR, contractility หรือ SVR?
  5. ให้ fluid challenge เฉพาะเมื่อมีเหตุผลว่า fluid responsive
  6. พิจารณา inotrope/vasopressor ตามกลไก
อย่าเพิ่ม fluid rate เป็นคำตอบอัตโนมัติของ MAP ต่ำ โดยเฉพาะแมว CKD และ cardiac disease

Hypercapnia / Hypoventilation

  1. Check depth / vaporizer
  2. Check ETT kink / obstruction / cuff
  3. Check circuit, dead space, absorber, fresh gas flow
  4. ETCO₂ >60 mmHg → เริ่ม PPV และประเมินซ้ำ
  5. หลัง PPV ให้ recheck BP

Hypoxemia

  1. Confirm ETT in trachea + O₂ source
  2. Check FiO₂ / circuit / leak
  3. แก้ hypoventilation
  4. Check one-lung intubation
  5. คิดถึง V/Q mismatch, atelectasis, pneumothorax, edema

Bradycardia

  1. ดู BP และ perfusion ก่อน
  2. ประเมิน anesthetic depth / vagal stimulus / drug effect
  3. ถ้า HR ต่ำแต่ perfusion ดี อาจยังไม่ต้องรักษาตัวเลข
  4. ถ้า HR ต่ำ + hypotension/poor perfusion → แก้สาเหตุและพิจารณายาที่เหมาะสม

Hypothermia

  1. หยุด heat loss: wet prep, cold surface, exposed cavity
  2. เริ่ม active warming ที่ปลอดภัย
  3. อุ่น fluids หากเหมาะสม
  4. ลดเวลาสลบที่ไม่จำเป็น
  5. monitor ต่อใน recovery
