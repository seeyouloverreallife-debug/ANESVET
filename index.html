Clinical events on timeline

ยังไม่มี note/event

Hypotension

  1. Verify BP + pulse/perfusion
  2. Assess anesthetic depth → ลด inhalant ถ้าลึก
  3. Optimize analgesia / local block
  4. ถามว่า volume, HR, contractility หรือ SVR?
  5. Fluid challenge เฉพาะเมื่อมีเหตุผลว่า fluid responsive
  6. พิจารณา inotrope/vasopressor ตามกลไก

Hypercapnia / Hypoventilation

  1. Check depth / vaporizer
  2. Check ETT kink / obstruction / cuff
  3. Check circuit, dead space, absorber, fresh gas flow
  4. ETCO₂ >60 → PPV + reassess
  5. หลัง PPV ให้ recheck BP

Hypoxemia

  1. Confirm ETT + O₂ source
  2. Check FiO₂ / circuit / leak
  3. แก้ hypoventilation
  4. Check one-lung intubation
  5. คิดถึง V/Q mismatch, atelectasis, pneumothorax, edema

Bradycardia

  1. ดู BP และ perfusion
  2. ประเมิน depth / vagal stimulus / drug effect
  3. HR ต่ำแต่ perfusion ดีอาจไม่ต้องรักษาตัวเลข
  4. HR ต่ำ + hypotension/poor perfusion → แก้สาเหตุ

Hypothermia

  1. หยุด heat loss
  2. active warming
  3. อุ่น fluids หากเหมาะสม
  4. ลดเวลาสลบที่ไม่จำเป็น
  5. monitor ต่อใน recovery
