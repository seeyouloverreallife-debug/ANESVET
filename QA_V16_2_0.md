## Intentional behavioral changes

- Mobile navigation is reduced to one primary navigation surface.
- OR context becomes sticky only after the full OR header leaves the viewport.
- OR detailed workflow status is on-demand in focused phone/tablet layouts.
- Recovery sections use progressive disclosure and reveal themselves when targeted by existing Next-task/More actions.
- Recovery Readiness Score defaults collapsed only for a fresh V16.2 UI preference state; existing saved progressive-disclosure preference is respected.
