# QA — ANESVET V16.8.3 Mobile Dock Hotfix

## Scope
CSS/runtime version hotfix only. No clinical logic or data schema changes.

## Regression targets
- OR LIVE mobile dock stays fully inside viewport
- Recovery mobile dock stays fully inside viewport
- VITALS / MORE / primary workflow button remain reachable
- Desktop/tablet layout unchanged outside mobile breakpoint
- JavaScript syntax valid
- HTML IDs unique
- Service worker asset list complete

## Root cause guard
At mobile breakpoint the final computed dock geometry must not combine:
- left/right edge insets
- with `transform: translateX(-50%)`

V16.8.3 explicitly resets the transform and width in `clinical-calm.css`.
