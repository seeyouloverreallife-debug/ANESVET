# QA — ANESVET V17.2.0 Backend-ready Sync & Conflict Review

## Scope
V17.2.0 hardens the experimental synchronization layer introduced in V17.1.0. It adds a provider-neutral HTTP/LAN transport contract, persistent case-level conflict holds, evidence-only conflict review, preview-only remote pull, case-snapshot queue coalescing, and deterministic transport fault injection.

This release still does **not** include a production canonical server and does **not** claim production-safe concurrent multi-device editing.
