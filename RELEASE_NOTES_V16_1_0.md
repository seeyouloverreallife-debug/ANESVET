# ANESVET V16.1.0 — Clinical Calm Visual Refresh

## Summary
V16.1 introduces a shared visual/UX system focused on modern, restrained clinical presentation. It keeps V16.0 clinical behavior and record architecture intact.

## Changes
- Added `clinical-calm.css` as a final visual override layer.
- New neutral/off-white surface system and restrained teal identity.
- Reduced gradients, shadows, heavy borders and excessive bold text.
- Restyled global navigation, panels, buttons, inputs, dialogs, status pills and timeline items.
- OR LIVE redesigned as a calmer clinical workspace:
  - simplified dark command header
  - large vital numerals
  - thin status accents for good/warning/critical
  - quieter routine status surfaces
  - stronger single primary action hierarchy
- Recovery redesigned with lighter timing/latest-observation surfaces and simplified action hierarchy.
- Mobile OR/Recovery dock refreshed as a compact floating dock with safe-area support.
- Tablet and mobile responsive refinements.
- Added reduced-motion support.
- Updated PWA metadata/cache namespace to V16.1.0.

## Safety / compatibility
- No dose changes.
- No alert-threshold changes.
- No medication-safety changes.
- No protocol-review changes.
- No reconciliation/finalization changes.
- Existing storage keys and case schema retained.
- No data migration required from V16.0.
