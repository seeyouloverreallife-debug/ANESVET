# ANESVET V17.2.6 R02 — เริ่มที่นี่

**ไฟล์นี้เป็น Checkpoint ต่อจาก V17.2.5 R01 ไม่ใช่โปรแกรมสร้างใหม่**

- อ่าน `BUGFIX_CHECKPOINT_R02_TH.md` สำหรับสรุปการแก้ไข การทดสอบ และ R03
- อ่าน `DEVICE_R02_TEST_STEPS_TH.md` สำหรับการทดสอบบน Android / iPad
- อัปโหลด **ไฟล์ภายในโฟลเดอร์นี้ทั้งหมด** ไปยัง root ของ GitHub Pages repo; ไม่อัปโหลดเพียงโฟลเดอร์ชั้นนอก
- ยืนยันว่าเว็บไซต์แสดง V17.2.6; ถ้าไม่ใช่ให้หยุดการทดสอบรอบนี้

- เครื่องที่มีเคสกำลังทำงาน: สำรองข้อมูลที่สำคัญก่อน deploy; อย่า Reset/Clear Data/ถอนแอป

**การนำ R02 ไปทำต่อ**: ใช้โฟลเดอร์นี้เป็น source checkpoint ให้ระบบทดสอบจริงและอ่าน Diagnostic ก่อนเลือกแก้โมดูลใน R03.

หมายเหตุ: checksum/QA files ที่ชื่อ V17.2.5 เป็นบันทึกของรุ่นก่อนหน้า ไม่ใช่ checksum ของ R02; ใช้ `PACKAGE_SHA256_R02.json` สำหรับไฟล์ R02.
