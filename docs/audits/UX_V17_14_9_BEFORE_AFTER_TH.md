# ผลปรับความสะดวกในการใช้งาน V17.14.9

ทดสอบด้วยเคสสังเคราะห์และหน้าจอ 390 × 844 px ใน Edge เพื่อเปรียบเทียบกับ V17.14.8 โดยใช้ข้อมูลและลำดับการตรวจเดียวกัน

| หน้า | ก่อนปรับ | หลังปรับเมื่อพับรายละเอียด |
|---|---:|---:|
| ผู้ป่วย | 4,912 px | 2,609 px |
| Pre-check | 5,488 px | 1,175 px |
| ยา / Drug Plan | 10,689 px | 3,405 px |
| End Case | 3,782 px | 3,022 px |

ตัวเลขเป็นความสูงหน้าในสภาพที่ทดสอบ ไม่ใช่เวลาทำงานที่วัดกับผู้ใช้จริง เมื่อเปิดรายละเอียด หน้าจะยาวขึ้นตามข้อมูลที่ต้องทบทวน

ปุ่มบันทึก Vitals เปลี่ยนจาก 42 × 40 px เป็น 338 × 48 px ที่ความกว้าง 390 px และเต็มแถบที่ความกว้าง 1024 px
ข้อมูลยา Dose / Concentration / Route ข้อควรระวัง และยาที่รอบันทึกยังอยู่ในขั้นตอนหลัก
Details เปิดได้ด้วยการแตะและคีย์บอร์ด ส่วนการไปยังช่องที่ซ่อนอยู่จะเปิดหมวดนั้นให้ก่อน
ปุ่ม Save assessment ยังคงกันคำตอบไม่ครบ ส่วน N/A ต้องมีเหตุผลตามระบบเดิม
End Case ยังต้องผ่านการตรวจ Recovery, การทบทวนยา, Sign-off และ Final checklist เดิม

ข้อจำกัด: ยังไม่ได้ทดสอบกับมือถือของผู้ใช้หรือเก็บผลการทดลองกับผู้ใช้จริง และยังไม่ได้เผยแพร่ขึ้นเว็บไซต์
