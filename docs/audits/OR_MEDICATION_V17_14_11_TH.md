# ผลตรวจและแก้ OR V17.14.11

ตรวจด้วยเคสสังเคราะห์ในเบราว์เซอร์ แล้วทดสอบซ้ำกับแอปเต็มหลังแก้

1. หน้าทบทวน Induction อ้างตัวแปร tapTime ที่ไม่มีอยู่ ทำให้เกิด ReferenceError ก่อนเปิด dialog แก้ให้ใช้สถานะเวลาของ provisional record ที่มีอยู่
2. addEvent แปลงค่าเริ่มต้น null เป็นเลข 0 ทำให้เวลาเหตุการณ์และระยะเวลาเป็นค่าเริ่มต้นผิด แก้ให้ null / undefined / ข้อความว่างใช้ Date.now() และ currentElapsed() ส่วนค่าเวลาที่ระบุจริงยังถูกใช้ตามเดิม
3. การบันทึกยาทบทวนเคยแปลงช่องเวลาแม้ผู้ใช้ไม่ได้แก้ ทำให้มิลลิวินาทีเดิมหายไป แก้ให้แปลงเฉพาะเมื่อค่าเวลาเปลี่ยน โดยยังใช้การแปลงเวลาข้ามเที่ยงคืนและหมายเหตุปรับเวลาเดิม
4. รูปแบบ label และปุ่มทำให้ hidden บางส่วนของหน้าทบทวนยาไม่ถูกซ่อน แก้เฉพาะ medication dialog ให้เคารพ hidden และจัดปุ่มมือถือสองคอลัมน์
5. เมนู OR เดิมตั้ง tabIndex=-1 ทุกปุ่มเมื่ออยู่ Monitor ทำให้ Tab เข้าไม่ถึง แก้ให้มีจุดเข้าหนึ่งจุด รักษาตำแหน่งเมนูล่าสุด และใช้ลูกศร / Home / End ย้ายงาน ปุ่มมี aria-pressed และเชื่อมกับบริเวณข้อมูลที่ระบุชื่อไว้

ผลทดสอบใหม่ 132/132 ผ่าน: เวลาเหตุการณ์ใหม่ตรงกับขณะกด, ระยะเวลาจาก timer, manual actual, เปลี่ยน calculated actual, เวลาเดิมและเวลาที่แก้เอง, ยกเลิกการยืนยัน, review ที่ยังค้าง, reload และการใช้คีย์บอร์ด ที่ 360×844, 390×844, 1024×844 และ 844×390 px

สูตรคำนวณและเงื่อนไขบันทึกยาไม่ได้เปลี่ยน การแก้เวลาไม่ได้เปลี่ยนข้อมูลเคสเก่าย้อนหลัง ภาพและรายงานเป็นเคสสังเคราะห์ ไม่ใช่ข้อมูลผู้ป่วยจริง ยังไม่ได้ทดสอบคีย์บอร์ดจริงบนโทรศัพท์หรือเผยแพร่ขึ้นเว็บไซต์
