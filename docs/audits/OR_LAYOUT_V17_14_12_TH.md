# ผลตรวจและแก้ภาพหน้า OR V17.14.12

สาเหตุ: CSS workspace ที่โหลดทีหลังกำหนด grid เป็นคอลัมน์ข้อความและคอลัมน์ปุ่ม auto เมื่อเพิ่ม Undo ข้างปุ่มขั้นตอน ปุ่มรวมกันกินความกว้างจนหัวข้อเหลือ 0 px ที่ความกว้าง 390 px

แก้ให้หัวข้ออยู่แถวเต็มความกว้างเหนือแถวปุ่ม ปุ่มย้ายแถวได้เมื่อพื้นที่ไม่พอ และแก้ลำดับซ้อนของ Undo จากปุ่มลอยเดิมเพื่อไม่ให้แทรกการแตะปุ่มแถบล่าง

ผลเปรียบเทียบเคสสังเคราะห์ที่ 390×844 px: หัวข้อกว้าง 0 → 338 px ความสูงหัวข้อ 139.1 → 23.2 px ความสูงการ์ด 183.1 → 139.8 px ปุ่ม Extubation และ Undo ไม่ซ้อนกัน

ผู้ใช้ยืนยันว่าภาพเป็นเคสเดิมที่เปิดค้างหรือเปิดกลับมา ค่า FIRST DUE คำนวณจาก interval ลบ elapsed ของ timer จึงยังคงแสดงเวลาเลยกำหนดเมื่อยังไม่มี record แรก เปลี่ยนเฉพาะข้อความจากนาทีรวมเป็นรูปแบบ ชั่วโมง:นาที:วินาทีเมื่อเกินหนึ่งชั่วโมง ไม่ได้ปรับเวลาหรือประวัติของเคสเดิม

การทดสอบใหม่ 185/185 ผ่านในเบราว์เซอร์ที่ 320×844, 360×844, 390×844, 1024×844 และ 844×390 px รวมแตะขั้นตอนจริง Undo กลับจาก Surgery end บันทึก Vitals reload และยืนยัน Extubation ไป Recovery การทดสอบตัวอักษรใหญ่เป็นการจำลองรูปแบบ ไม่ใช่การทดสอบการตั้งค่าขนาดตัวอักษรบนมือถือจริง

ภาพเปรียบเทียบและข้อมูลทั้งหมดใช้เคสสังเคราะห์ ไม่ได้รวมภาพผู้ใช้หรือข้อมูลผู้ป่วยจริงลง ZIP และยังไม่ได้เผยแพร่ขึ้นเว็บไซต์
