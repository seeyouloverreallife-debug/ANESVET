# การแก้ข้อความยืนยันหน้า OR V17.14.10

สาเหตุของแถบดำใหญ่: การกำหนดตำแหน่งด้านบนและด้านล่างพร้อมกันจากกฎหน้าจอคนละชุดทำให้ข้อความสั้นมีความสูง 96 px การแก้กำหนดขอบด้านบนเพียงด้านเดียวและให้ความสูงตามข้อความ

ทดสอบที่ 390 × 844 px: ข้อความบันทึกบรรทัดเดียวสูงประมาณ 36 px และข้อความ Intubation ที่ขึ้นสองบรรทัดสูงประมาณ 57 px ปุ่ม Undo หลัง Intubation กว้างประมาณ 162 px สูง 44 px อยู่ในแถวปุ่มขั้นตอนโดยไม่ซ้อนกับ Surgery start

หน้า OR รูปแบบมือถือใช้ toast ยืนยันครั้งเดียว ส่วนข้อความสรุปรายการที่บันทึกยังแสดงในรายการล่าสุด การบันทึกจริง ปุ่ม Undo และเวลาแสดงข้อความใช้กลไกเดิม

ตรวจเทียบกับไฟล์รุ่นก่อนพบว่าการแก้ JavaScript นอกเลขรุ่นมีเพียงการซ่อนข้อความยืนยันที่ซ้ำใน mobile shell และย้ายปุ่ม Undo เดิมเข้ากลุ่มปุ่มขั้นตอน ไม่มีการแก้ส่วนคำนวณหรือเงื่อนไขการบันทึกทางคลินิก

การทดสอบใหม่ใช้เคสสังเคราะห์ในเบราว์เซอร์ที่ 360, 390 และ 1024 px ข้อความเตือนยาวที่ใช้ทดสอบรูปแบบเป็นข้อความจำลอง ไม่ใช่หลักฐานของการทดสอบเงื่อนไขทางคลินิกนั้น การทดสอบสถานะ editing เป็นการตรวจรูปแบบ ไม่ได้ทดสอบคีย์บอร์ดจริงบนโทรศัพท์
