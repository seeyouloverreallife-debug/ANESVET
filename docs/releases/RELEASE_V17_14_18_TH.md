# ANESVET V17.14.18 — Dose Reference ในคำนวณยาเร็ว

เพิ่มข้อมูลขนาดยาอ้างอิง 32 ยา / 50 บริบท จาก 8 เอกสารต้นทาง
รองรับรายชื่อ 62 ยา 10 หมวด และยาอื่น ๆ เช่นเดิม

เปิดใช้
- แตก ZIP และเปิด/โฮสต์ด้วยวิธีเดิม ตรวจเลขรุ่น V17.14.18
- หน้าแรก → คำนวณยาเร็ว; ไม่ต้องสร้างเคส
- เข้าจากเพิ่มเติม หรือคลังความรู้ → ยา ได้เช่นเดิม

วิธีเลือก Dose Reference
1. เลือกยาและชนิดสัตว์ แล้วกรอกน้ำหนัก kg
2. เปิด Dose Reference เลือกบริบท เช่น induction หรือ sedation
3. อ่านช่วงขนาดยา วิธีให้ ข้อจำกัด และต้นทางที่ระบุ
4. เลือกวิธีให้ยา และกรอกขนาดที่สัตวแพทย์เลือกภายในช่วง
   ถ้าเป็นขนาดตายตัวจะแสดงค่าของบริบทนั้น แต่ยังไม่เติมในเครื่องคำนวณ
5. กด “ยืนยันใช้ขนาดนี้ในเครื่องคำนวณ”
6. กรอกความเข้มข้นจริงตามฉลาก/หลังเตรียม แล้วกดคำนวณ
7. ผลและข้อความคัดลอกมีบริบท วิธีให้ยา แหล่งอ้างอิงและวันที่ตรวจ

ข้อมูลและข้อจำกัด
- ตรวจแหล่งอ้างอิงวันที่ 2026-10-11 จาก AAHA, Merck, RECOVER และ ENOVAT
- ตาราง ENOVAT 2025 ฉบับตีพิมพ์ปี 2026 เป็นข้อมูลอ้างอิงใหม่ในหน้านี้
  ข้อมูลเดิมในแผนยาและโปรแกรมดูแลเคสไม่ถูกแทนที่
- บริบท CPR ของยา emergency/reversal ไม่ใช่สูตร reverse ทั่วไป
- induction ให้ปรับช้า ๆ ตามผล ไม่ใช่ให้ทั้งหมดตามปริมาตรที่คำนวณได้
- ขนาดต่อวัน, mg/ตัว, ยาชาที่ต้องรวมทุกจุด, เพดานตัวยารวม และสูตรผสม
  ที่ต้องยืนยันฐานความแรง แสดงให้อ่านและกำหนดต่อครั้งเอง ไม่เติมอัตโนมัติ
- ยาหรือชนิดสัตว์ที่ยังไม่มีข้อมูลจะแสดงสถานะชัดเจน กรอกขนาดเองได้
- ยาอื่น ๆ ไม่จับคู่ชื่อที่กรอกกับ Dose Reference แม้ใช้ชื่อคล้ายยาในคลัง
- สูตรคำนวณยังเป็น mg/kg หรือ mcg/kg ต่อครั้ง → ปริมาตรยาน้ำ/ฉีด
  ไม่รองรับ CRI, IU, mEq, %, จำนวนเม็ด หรือยาดมสลบ
- ไม่มีค่าความเข้มข้นที่เติมอัตโนมัติ

เมื่อเปลี่ยนข้อมูล
- เปลี่ยนชนิดสัตว์/บริบท/วิธีให้/ขนาดในแผงอ้างอิง: ล้างขนาดที่เคยนำไปใช้และผล
- เปลี่ยนยา/หมวด/แก้ชื่อยาอื่น ๆ: ล้างขนาด ความเข้มข้น และผล
- แก้ขนาดหรือหน่วยในเครื่องคำนวณเอง: ยกเลิกการระบุว่าใช้ Dose Reference
- แก้น้ำหนักหรือความเข้มข้น: ล้างผลเพื่อคำนวณใหม่โดยคงบริบทที่เลือก
- ปิด/ล้างค่า: ล้างทุกค่า ไม่เปลี่ยนข้อมูลเคสหรือบันทึกการให้ยา

การตรวจซอฟต์แวร์
- 4068/4068 ผ่านใน 29 ชุดตรวจ
- คำนวณเดิม/หมวดยา/ชื่อยาอื่น ๆ 1660/1660 ผ่าน
- Dose Reference 756/756 ผ่าน
- ครบ 320×844, 390×844, แนวนอน 667×375 และคอมพิวเตอร์ 1024×844
- ตรวจการแยกชนิดสัตว์ บริบท หน่วย ช่วงตัวเลข การยืนยัน การล้างข้อมูล
  การคัดลอกแหล่งอ้างอิง การอ่านอย่างเดียว และการใช้งานหลังโหลดแบบออฟไลน์
- สูตรเดิม ข้อมูลเคส แผนยาที่แช่แข็ง และข้อมูลยาในโปรแกรมดูแลเคสคงเดิม

การตรวจซอฟต์แวร์ไม่ใช่การรับรองโดสทางคลินิก
ยังไม่มี independent clinical signoff; ให้สัตวแพทย์ตรวจผู้ป่วย ฉลาก และแนวทางโรงพยาบาล
ก่อนใช้เป็นข้อมูลประกอบการตัดสินใจจริง ยังไม่ได้เผยแพร่เว็บไซต์หรือทดลองบนมือถือเครื่องจริง
