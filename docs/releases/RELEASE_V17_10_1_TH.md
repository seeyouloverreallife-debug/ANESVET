# ANESVET V17.10.1 — Patient & Pre-op Simplification

- Patient setup now starts with core case data and hides secondary details until requested.
- No patient fields were deleted. Visit ID, reproductive status, microchip, detailed age, BCS, workflow override and case team remain available under additional details.
- Required-state summary shows missing Name / Species / Current BW / Procedure / ASA.
- Pre-op adds a single next-action surface driven by existing checklist progress.
- It never marks checklist items Done/N/A automatically.
- Existing Physical Exam, Risk Flags, checklist, BW confirmation, native Patient save and safety gates are preserved.
