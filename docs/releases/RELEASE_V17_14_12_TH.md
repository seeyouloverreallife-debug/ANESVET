# ANESVET V17.14.12

แก้ต่อจาก V17.14.11 ตามภาพหน้า OR ที่หัวข้อ Emergence เรียงตัวอักษรลงแนวตั้ง
รวมการแก้ข้อความบันทึก / Undo / หน้าทบทวนยา / เวลาเหตุการณ์ใหม่จากรุ่นก่อนแล้ว
ใช้งาน: แตก ZIP แล้วใช้กับวิธีเปิด/โฮสต์เดิมของ ANESVET
หลังอัปเดตตรวจเลขรุ่น V17.14.12 โดยไม่ล้างข้อมูลเว็บไซต์หรือเคส

สิ่งที่แก้
- หัวข้อขั้นตอนอยู่เหนือแถวปุ่ม ใช้พื้นที่เต็มบรรทัด จึงไม่ถูก Extubation และ Undo บีบจนเรียงตัวอักษรลงมา
- ปุ่มย้ายลงแถวใหม่ได้เมื่อจอแคบ ข้อความขึ้นหลายบรรทัดได้และปุ่มสูงอย่างน้อย 48 px
- ปุ่ม Undo ที่ย้ายมาอยู่ข้างขั้นตอนไม่ทับแถบ Save / เมนูด้านล่างเมื่อเลื่อนหน้า
- เวลาที่เลยกำหนดเกินหนึ่งชั่วโมงใน OR เปลี่ยนจากนาทีรวม เช่น +1273:44 เป็น +21:13:44 (ชั่วโมง:นาที:วินาที)
- ค่า FIRST DUE ของเคสเก่าเป็นเวลาที่เลยกำหนดบันทึกชุดแรก การแก้ครั้งนี้เปลี่ยนการแสดงผล โดยไม่ได้รีเซ็ต timer หรือข้อมูลเคส
- ปรับเลขรุ่นและ cache เพื่อให้โหลดหน้าจอที่แก้แล้ว

การตรวจสอบ
- 992/992 checks ผ่าน ใน 24 QA scripts
- การทดสอบใหม่ 185/185 ผ่าน ที่ 320×844, 360×844, 390×844, 1024×844 และ 844×390 px
- แตะปุ่มจริงตั้งแต่ Induction / Intubation / Surgery start / Surgery end ไปจน Extubation และ Recovery
- ทดสอบหัวข้อไม่ถูกบีบ ปุ่มไม่ซ้อน ข้อความครบ ตัวอักษรใหญ่ขึ้น และปุ่มแถบล่างไม่ถูก Undo บัง
- ทดสอบ Undo ย้อน Surgery end, บันทึก Vitals ชุดแรก, กำหนดถัดไปจาก record ใหม่ และเปิดกลับหลัง reload
- ตรวจเทียบกับ V17.14.11: JavaScript เปลี่ยนเฉพาะรูปแบบข้อความ overdue ใน OR นอกเหนือจากเลขรุ่น กลไก timer / สูตรยา / การยืนยันบันทึก / ข้อมูลเคสเดิมคงเดิม
