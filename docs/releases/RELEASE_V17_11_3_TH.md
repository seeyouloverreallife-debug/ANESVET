# ANESVET V17.11.3 — BUG CENTER / OR Ownership Hotfix

## Device-reported root cause fixed
`clinical-simplicity.js` was a legacy presentation module that still attempted to reorder OR LIVE nodes with `insertBefore()`.  
V17.11 moved those nodes into the task-based OR workspace, so the reference node was no longer a direct child of the original OR page.

V17.11.3:
- Delegates OR LIVE layout completely to `ANESVET_OR_WORKSPACE` when the V17.11 owner exists.
- Keeps a legacy fallback only when both nodes are verified as direct children of the same page.
- This removes the reported `NotFoundError` without changing clinical state.

## BUG CENTER release scoping
The recovery-handoff errors showing `?v=17.10.6` and `?v=17.10.7` were persisted historical Bug Center entries.  
The V17.11.2 diagnostic itself showed `startup-complete`, `ready: true`, and `anesvetApp: true`.

V17.11.3:
- stores `version` on every new Bug Center issue;
- displays only issues recorded by the current release;
- moves prior/legacy issue entries to a small local diagnostic archive instead of mixing them into the current Bug Center;
- does not suppress or clear errors generated by the current release.

The V17.10.8 non-throwing recovery-handoff startup fix remains intact.

## Preserved
V17.11 OR workspaces, Induction given/details-pending workflow, editable individual induction medication time, timestamp-only Intubation, End Surgery, Emergency Return, Recovery, Calculated-as-Given, Final Lock and archive verification.
