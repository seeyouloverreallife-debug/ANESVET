# ANESVET V17.14.16 — คำนวณยาเร็ว

เครื่องคำนวณสำหรับยาวางสลบและยารอบผ่าตัด 30 รายการจากคลังความรู้เดิม
เปิดจากหน้าแรกได้โดยไม่ต้องสร้างเคส ผลคำนวณเป็นเครื่องมือทดเลขแยกจากเคส
รวมการแก้ระยะขอบคลังความรู้และการบันทึก Vaporizer/O₂ จากรุ่นก่อนแล้ว

ติดตั้ง/อัปเดต
- แตก ZIP แล้วใช้วิธีเปิดหรือโฮสต์เดิมของ ANESVET
- ตรวจเลขรุ่น V17.14.16 หลังอัปเดต โดยไม่ล้างข้อมูลเว็บไซต์หรือเคส

เปิดใช้งาน
- หน้าแรก → คำนวณยาเร็ว
- เพิ่มเติม → คำนวณยาเร็ว
- คลังความรู้ → ยา → คำนวณยาเร็ว
- รายละเอียดในคลังยา → คำนวณปริมาณยานี้ (เลือกชื่อยาไว้ให้เท่านั้น)

วิธีคำนวณ
1. เลือกชื่อยาและชนิดสัตว์: สุนัข / แมว
2. กรอกน้ำหนัก kg ที่ต้องการใช้คำนวณ
3. กรอกขนาดยาที่สัตวแพทย์กำหนดต่อครั้ง และเลือก mg/kg หรือ mcg/kg
4. กรอกความเข้มข้นของยาที่ใช้จริงหลังเตรียม/เจือจาง และเลือก mg/mL หรือ mcg/mL
5. กดคำนวณ ดูปริมาณตัวยารวมและปริมาตร mL พร้อมสูตรตรวจย้อนกลับ
6. คัดลอกผลพร้อมชื่อยา ชนิดสัตว์ น้ำหนัก ขนาดยา หน่วย และความเข้มข้นได้

รายละเอียดการใช้งาน
- ตัวคำนวณแปลง mg/mcg โดยใช้ 1 mg = 1,000 mcg
- ไม่กรอกขนาดยาต่อวันหรือต่อชั่วโมง/อัตรา CRI ในช่องขนาดยาต่อครั้ง
- ช่องน้ำหนัก ขนาดยา และความเข้มข้นเริ่มว่าง ไม่มีขนาดยาหรือความเข้มข้นที่ตั้งให้เอง
- การเลือกชื่อยาไม่ยืนยันว่ายานั้นเหมาะกับสัตว์ชนิดที่เลือกหรือผู้ป่วย
- ปุ่ม “อ่านความรู้ของยานี้” แสดงข้อมูลเชิงคุณภาพและแหล่งอ้างอิงจากคลังเดิม
- เมื่อเปลี่ยนค่าใด ผลเดิมและการคัดลอกจะถูกล้างทันที ต้องกดคำนวณใหม่
- เมื่อเปลี่ยนยา ขนาดยา ความเข้มข้น และหน่วยจะถูกล้าง/ตั้งกลับเพื่อให้กรอกใหม่
  ชนิดสัตว์และน้ำหนักคงไว้เพื่อเทียบยาในสัตว์ตัวเดิม
- ปิดหน้าต่างหรือกดล้างค่า จะล้างค่าทั้งหมด ไม่เก็บประวัติลงข้อมูลเคส
- ค่าเป็นศูนย์ ติดลบ ว่าง หน่วยไม่รองรับ หรือตัวเลขที่อ่านไม่ได้ จะไม่แสดงผล
- ผลเล็กไม่ถูกปัดเป็น 0; ปริมาตรต่ำกว่า 0.01 mL มีข้อความให้ตรวจหน่วยและการตวง
- ผลแสดงประมาณ 10 หลักนัยสำคัญ ยังไม่ปัดตามขีดแบ่งอุปกรณ์ตวง
- ค่าที่กรอกยังแสดงทศนิยมครบในฐานคำนวณและข้อความที่คัดลอก
- หากเบราว์เซอร์ไม่อนุญาตคัดลอก มีช่องข้อความให้เลือกคัดลอกเอง
- ใช้เครื่องคำนวณที่โหลดแล้วต่อได้เมื่อออฟไลน์

การตรวจสอบ
- 3204/3204 รายการผ่านใน 28 ชุดตรวจ
- ตัวคำนวณใหม่ 1552/1552 ผ่าน
- ตรวจสูตรอิสระหลายชุดค่ารวม 4 คู่หน่วย mg/mcg และข้อมูลที่คำนวณไม่ได้
- ตรวจมือถือ 320×844, 390×844, แนวนอน 667×375 และคอมพิวเตอร์ 1024×844
- ตรวจเริ่มโดยไม่มีเคส การเปลี่ยนยา/ค่าเดิม ล้างค่า ปิด-เปิดใหม่ คัดลอกและกรณีคัดลอกไม่ได้
- ตรวจชื่อยาและแหล่งอ้างอิงครบ มีระยะขอบ และไม่มีการล้นจอในหน้าคำนวณ
- ยืนยันข้อมูลเคสทั้งหมด น้ำหนักในเคส แผนยาแช่แข็ง และรายการให้ยาไม่เปลี่ยน
- กลไกเคสและข้อมูลทางคลินิกเดิมคงเดิมนอกเหนือจากเลขรุ่น
- การตรวจนี้รับรองการทำงานและสูตรคำนวณ ไม่ใช่การรับรองการเลือกยา/ขนาดยาทางคลินิก
- เนื้อหาความรู้เดิมยังมีสถานะการทบทวนโดยผู้เชี่ยวชาญอิสระตามที่ระบุในคลัง
