# ANESVET V17.14.10

ปรับต่อจาก V17.14.9 โดยรวมการแก้ความสะดวกในการใช้งานและ Vent / Medication ก่อนหน้านี้ไว้แล้ว
ใช้งาน: แตก ZIP แล้วใช้กับวิธีเปิด/โฮสต์เดิมของ ANESVET
หลังอัปเดตตรวจว่าเลขเวอร์ชันเป็น V17.14.10 โดยไม่ล้างข้อมูลเว็บไซต์หรือเคส

สิ่งที่แก้ตามอาการที่รายงาน
- แถบดำแจ้งบันทึกสำเร็จสูงตามข้อความ จาก 96 px เหลือประมาณ 36 px สำหรับข้อความบรรทัดเดียวในหน้าจอที่ทดสอบ
- ข้อความยาวยังขึ้นหลายบรรทัดให้อ่านครบ ไม่ขยายแถบจนเต็มพื้นที่แนวตั้ง
- หน้า OR ในรูปแบบมือถือแสดงข้อความยืนยันบันทึกเพียงชุดเดียว ลดข้อความลอยซ้อนกัน
- ปุ่ม Undo หลัง Induction / Intubation เป็นปุ่มสีอ่อนขนาดเล็กอยู่ข้างปุ่มขั้นตอน แทนแถบสีส้มยาวลอยทับหน้าจอ
- ปุ่ม Undo เดิมยังทำงาน และการบันทึก Vitals / กันบันทึกซ้ำ / รายการล่าสุดยังทำงานตามเดิม
- ปรับเลขรุ่นและ cache เพื่อให้โหลดส่วนแสดงผลที่แก้แล้ว

การตรวจสอบ
- 675/675 checks ผ่าน ใน 22 QA scripts
- การทดสอบใหม่ 60/60 ผ่านในเบราว์เซอร์ที่ความกว้าง 360, 390 และ 1024 px
- ทดสอบกด Induction / Intubation / Undo จริง บันทึก Vitals จริง และบันทึกซ้ำด้วยเคสสังเคราะห์
- ทดสอบว่าหน้าไม่เลื่อนเมื่อบันทึก ข้อความไม่ซ้อน ปุ่มย้อนกลับไม่บังปุ่มถัดไป และข้อความยาวยังอ่านได้
- การทดสอบ UX และ Vent / Medication จากรุ่นก่อนผ่านทั้งหมด
- ตรวจเทียบไฟล์ส่วนคำนวณและตัวควบคุมทางคลินิกกับ V17.14.9: เหมือนเดิมหลังเปลี่ยนเลขรุ่น
