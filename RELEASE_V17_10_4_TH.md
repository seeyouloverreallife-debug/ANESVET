# ANESVET V17.10.4 — Recovery → End Case Refinement

- Recovery Focus becomes the single visible primary completion path.
- Adds a read-only progress strip: Monitor → Readiness → Complete → Final Review.
- Duplicate top-level Recovery complete control remains as a compatibility action but is hidden during active Recovery.
- End Case exit card becomes prominent after Recovery completion instead of competing with active monitoring.
- Existing readiness criteria and documented override workflow are unchanged.
- Emergency Return to OR remains immediately available.
- Recovery panel navigation now uses the shared workspace owner and avoids forced scrolling while an editor / soft keyboard is active.
- Handoff, unresolved problems, medication reconciliation, sign-off, Final Lock and archive verification remain unchanged.
