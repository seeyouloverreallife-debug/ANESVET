V17.14.4 Physical Pilot telemetry
- ปิดเป็นค่าเริ่มต้น; กด Start device telemetry เมื่อต้องการ physical pilot
- เก็บ VisualViewport, keyboard inset, orientation, focus type, long tasks, BFCache/resume, optional JS heap
- Run device readiness เพิ่ม event-loop responsiveness probe
- Capture device snapshot เก็บ snapshot ครั้งเดียวได้แม้ continuous telemetry ปิด
- Export Production Pilot report เป็น V2 และรวม telemetry evidence
- ไม่เก็บค่าที่พิมพ์, patient/case payload, drug/vital values หรือ clinical notes
- telemetry local-only และไม่แก้ clinical state

Retained clinical contracts
- Induction prepared meds = Given / details pending
- administration time แก้ย้อนหลังได้
- Intubation timestamp-only
- Quick Drug / Fast Vital / End Surgery / Emergency Return / Recovery / Final Lock คงเดิม
- dose / concentration / thresholds / persistence schema ไม่เปลี่ยน
