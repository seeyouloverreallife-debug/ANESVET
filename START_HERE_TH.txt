V17.14.6 Physical Pilot UX Fix II
- Vent mode buttons เรียก canonical OR controller โดยตรง; Spontaneous / Manual PPV / Mechanical ventilation sync state และเปิด/ปิด RR/PIP/PEEP/VT ตาม mode
- คง Tramadol SC site-default และ standby/emergency medication filtering จาก V17.14.5
- Bottom navigation, Undo strip และ mobile overflow fixes จาก V17.14.5 ยังคงอยู่
- Recovery editable vitals เป็นงานแรก: HR / RR / SpO₂ / Temp / Mentation / Extubation พร้อม Record recovery vitals / Copy last
- MAP / O₂ support / interval / note / structured assessment ย้ายไว้ใน More observations
- Latest-vitals summary อยู่หลังช่องกรอก และ record history กลับไปอยู่ secondary details
- Recovery assessment กลับมาใช้ descriptive selects ที่อธิบายความหมาย 0/1/2/N/A และจัด layout ให้ minimal; ไม่มี numeric-only tap controls

Retained clinical contracts
- Induction prepared meds = Given / details pending
- administration time แก้ย้อนหลังได้
- Intubation timestamp-only
- Quick Drug / Fast Vital / End Surgery / Emergency Return / Final Lock คงเดิม
- dose / concentration / alert thresholds / persistence schema ไม่เปลี่ยน
- Emergency drugs ยังเข้าถึงได้ด้วย explicit selection; เปลี่ยนเฉพาะ auto-suggestion behavior

Physical pilot telemetry จาก V17.14.4 ยังคงอยู่และเป็น opt-in/local-only
