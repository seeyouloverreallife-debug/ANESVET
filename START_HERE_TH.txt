ANESVET V17.14.13 — OR Anesthesia / O₂ Adjustment Log

ต่อจาก V17.14.12 เพิ่มการบันทึกการปรับ Vaporizer และ O₂ แยกจากการบันทึก Vitals
รวมการแก้ข้อความบันทึก / Undo / หน้าทบทวนยา / เวลาเหตุการณ์ / หัวข้อ Emergence จากรุ่นก่อนแล้ว
ใช้งาน: แตก ZIP แล้วใช้กับวิธีเปิด/โฮสต์เดิมของ ANESVET
หลังอัปเดตตรวจเลขรุ่น V17.14.13 โดยไม่ล้างข้อมูลเว็บไซต์หรือเคส

วิธีบันทึกการปรับค่าเครื่อง
1. ในหน้า OR → Anesthesia เลือก Vaporizer (%) และ O₂ flow (L/min) ให้ตรงกับเครื่องจริง
2. ถ้าไม่มีตัวเลขที่ต้องการในปุ่มลัด เปิด “กรอกค่าเอง” แล้วกรอกค่า
3. ตรวจข้อความค่าเดิม → ค่าใหม่ ใส่หมายเหตุได้ถ้าต้องการ
4. กด “บันทึกการปรับยาสลบ / O₂” เมื่ออยากเก็บการปรับครั้งนั้น
5. เปิด “ประวัติการปรับค่าเครื่อง” เพื่อดูเวลาและค่าที่เปลี่ยน

โปรแกรมเป็นการบันทึกข้อมูล ไม่ได้สั่งเปลี่ยนค่าเครื่องจริง
ต้องเริ่มเคสก่อนบันทึก แต่ไม่ต้องกรอก Vitals เพื่อบันทึกการปรับค่าเครื่อง
การแตะตัวเลขหรือการบันทึกแบบร่างอัตโนมัติยังไม่สร้างรายการปรับค่าเครื่อง
ถ้าปรับหลายครั้งก่อนกดปุ่ม รายการจะเก็บค่าล่าสุดที่กดบันทึก
ค่าเดิมเทียบจากข้อมูลค่าเครื่องที่บันทึกไว้ล่าสุด ทั้งใน Vitals และในรายการปรับค่าเครื่อง
ช่องที่ยังไม่มีข้อมูลจะแสดง “ยังไม่ระบุ” และไม่ถือเป็น 0
ค่า 0 เป็นค่าที่ต้องเลือก/กรอกเอง และเก็บต่างจากช่องว่าง
หากค่าเหมือนรายการล่าสุด ปุ่มจะปิดเพื่อป้องกันการบันทึกซ้ำ

การดูย้อนหลังและส่งออก
- รายการปรับค่าเครื่องอยู่ในประวัติหน้า OR และ Timeline / Events
- Full PDF มีตารางการปรับค่าเครื่อง พร้อมเวลา ค่าเดิม → ค่าใหม่ และหมายเหตุ
- ตาราง Vitals และ Full PDF แสดง O₂ flow เพิ่มจาก Vaporizer
- Events CSV เพิ่มคอลัมน์ Vaporizer/O₂ ก่อนและหลังปรับ
- JSON backup เก็บข้อมูลรายการและค่าก่อน/หลังครบ
- “บันทึก Vitals” ยังเก็บค่าที่วัดพร้อมค่าเครื่องที่เลือกเหมือนเดิม
- การบันทึกเฉพาะค่าเครื่องไม่สร้าง Vitals ไม่เลื่อนกำหนดบันทึก Vitals และไม่เริ่มจับเวลาใหม่

การตรวจสอบ
- 1137/1137 checks ผ่าน ใน 25 QA scripts
- การทดสอบใหม่ 145/145 ผ่าน ที่ 320×844, 390×844 และ 1024×844 px
- ตรวจค่าที่ไม่ระบุ / 0 / ทศนิยม / ปรับทีละค่าและสองค่าพร้อมกัน / เปิดเคสกลับมา / บันทึกซ้ำ
- ตรวจการบันทึกล้มเหลวและการ retry โดยไม่สร้างรายการซ้ำ / case lock / note ไม่ข้ามเคส
- ตรวจ Timeline, Full PDF, CSV และ JSON ด้วยเคสสังเคราะห์
- ยังคงชุดทดสอบเดิมสำหรับขั้นตอน OR, Vitals, ยา, Undo, Recovery และการเก็บข้อมูล
