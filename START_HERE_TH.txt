ANESVET V17.14.9 — Usability Refinement

ปรับต่อจาก V17.14.8 ซึ่งแก้ Vent และ Medication queue แล้ว
ใช้งาน: แตก ZIP แล้วนำไฟล์ไปใช้กับวิธีเปิด/โฮสต์เดิมของ ANESVET
หลังอัปเดตตรวจว่าเลขเวอร์ชันเป็น V17.14.9 โดยไม่ล้างข้อมูลเว็บไซต์หรือเคส
ยังไม่ได้อัปโหลดไปเว็บไซต์หรือ GitHub

สิ่งที่ปรับ
- ปุ่มบันทึก Vitals เต็มช่อง สูงอย่างน้อย 48 px อ่านข้อความได้บนมือถือและแท็บเล็ต
- แยกสถานะบันทึกร่างในเครื่องออกจากยืนยันข้อมูลผู้ป่วย
- ข้อมูลผู้ป่วยหลัก, น้ำหนักปัจจุบัน, Procedure, ASA และข้อควรระวังอยู่ก่อนรายละเอียดเพิ่มเติม
- ค้นผู้ป่วยเดิม / อายุ / BCS / ทีมดูแล / Procedure templates เปิดดูได้เมื่อจำเป็น
- Pre-check แบ่งตรวจร่างกาย / ความเสี่ยง / Checklist และมีปุ่มถัดไปหลักหนึ่งปุ่ม
- Case Drug Plan อยู่ก่อน Quick Presets และเครื่องคำนวณ พร้อมแก้สีข้อความให้อ่านชัด
- Meds แสดงยาค้างตามแผนก่อนรายการยาเพิ่มเติม ลดปุ่ม All medications ซ้ำ
- ช่องปริมาณยาและ Route อยู่ก่อนข้อมูลอ้างอิง แต่ยังต้องยืนยันบันทึกการให้ยาจริง
- Recovery: หน่วย Temp ไม่แยกบรรทัด, Extubation ใช้ HH:MM, ปุ่มบันทึก assessment อยู่หลังคำตอบและบอกจำนวนที่ยังขาด
- End Case: พับรายละเอียดที่ซ้ำ แต่รายการค้าง ยา Sign-off และ Final action ยังเข้าถึงได้
- ผล Archive / Verify เปิดรายละเอียดให้ดูอัตโนมัติเมื่อสถานะเปลี่ยน
- แก้เส้นทางโหลดฟอนต์ Thai / Inter ใน CSS bundle

การตรวจสอบ
- 615/615 checks ผ่าน ใน 21 QA scripts
- ทดสอบการแตะและเปิดแอปเต็มที่ 390 และ 1024 px
- ทดสอบกรอก / ยืนยันผู้ป่วย / Review plan / เปิด Meloxicam / กลับโดยไม่ลงการให้ยา / assessment 10/10
- N/A ไม่มีเหตุผลยังถูกกัน และเคสที่ไม่พร้อมยัง Final Lock ไม่ได้
- ทดสอบ Vent save/reload และ Service Worker cache รุ่นใหม่
- สูตรยา dose / concentration, เกณฑ์ทางคลินิก และรูปแบบข้อมูลเคสเดิมยังคงเดิม
