V17.14.5 Physical Pilot UX Fix I
- Ventilator mode buttons ใช้ direct binding และ sync กับ authoritative ventilation select/mirror
- Tramadol ใช้ SC เป็น route default ตาม workflow ของโรงพยาบาลผู้ใช้ รวม frozen plan เก่าที่ route ว่าง
- Emergency/standby medications ไม่ถูก auto-suggest หรือ auto-advance เป็นยาถัดไป แต่ยังเลือกได้จาก All medications
- Bottom navigation ยังคงแสดงระหว่าง focus/input/keyboard และย่อให้กะทัดรัด
- Workflow transition Undo strip แสดงเด่นบน mobile; clinical records ยังคง correction/void audit trail
- เพิ่ม mobile overflow containment สำหรับข้อความ/section/table
- Recovery primary flow จัดเป็น Observations → Vital records → Score → Checklist
- Recovery score เพิ่ม tap-first controls 0/1/2/N/A และ Save disabled จนข้อมูล score ครบ

Retained clinical contracts
- Induction prepared meds = Given / details pending
- administration time แก้ย้อนหลังได้
- Intubation timestamp-only
- Quick Drug / Fast Vital / End Surgery / Emergency Return / Final Lock คงเดิม
- dose / concentration / alert thresholds / persistence schema ไม่เปลี่ยน
- Emergency drugs ยังเข้าถึงได้ด้วย explicit selection; เปลี่ยนเฉพาะ auto-suggestion behavior

Physical pilot telemetry จาก V17.14.4 ยังคงอยู่และเป็น opt-in/local-only
