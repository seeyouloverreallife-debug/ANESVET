ANESVET V17.14.11 — OR Medication & Navigation Fix

พัฒนาต่อจาก V17.14.10 รวมการแก้แถบดำยืนยันบันทึกและปุ่ม Undo ไว้แล้ว
ใช้งาน: แตก ZIP แล้วใช้กับวิธีเปิด/โฮสต์เดิมของ ANESVET
หลังอัปเดตตรวจเลขรุ่น V17.14.11 โดยไม่ล้างข้อมูลเว็บไซต์หรือเคส

สิ่งที่แก้
- แก้หน้าทบทวนยา Induction เปิดไม่ขึ้นเมื่อแตะยาที่เตรียมไว้
- แก้เวลาเหตุการณ์ใหม่ที่ไม่ได้ระบุเวลาเอง ให้ใช้เวลาขณะกดและระยะเวลาจริงจาก timer
- เมื่อทบทวนยาโดยไม่แก้เวลา จะเก็บเวลาเดิมของรายการ รวมส่วนมิลลิวินาที
- เมื่อแก้ Administration time เอง ยังบันทึกเวลาที่เลือกพร้อมหมายเหตุปรับเวลาตามระบบเดิม
- ซ่อนตัวเลือกยาที่ซ้ำและช่องที่ระบบไม่ต้องการแสดงในหน้าทบทวนยา ตามสถานะ hidden ของระบบเดิม
- ปุ่ม “ยืนยันทบทวนยา” แยกความหมายจาก “บันทึกยาจริง” และจัดปุ่มบนมือถือเป็นสองคอลัมน์ให้อ่านได้
- เมนู Fluid / Vent / Airway / Meds เข้าถึงด้วย Tab ได้ ใช้ลูกศร / Home / End เลือกงานได้
- กลับ Monitor แล้วตำแหน่งคีย์บอร์ดกลับไปที่เมนูที่เห็นอยู่ ไม่ค้างในส่วนที่ซ่อน
- ปรับเลขรุ่นและ cache สำหรับไฟล์ใหม่

การตรวจสอบ
- 807/807 checks ผ่าน ใน 23 QA scripts
- การทดสอบใหม่ 132/132 ผ่านที่ 360×844, 390×844, 1024×844 และ 844×390 px
- ทดสอบเปิดยา Induction จริง กรอก manual actual เปลี่ยน actual จาก calculated amount และบันทึกจริงในเคสสังเคราะห์
- ทดสอบยกเลิก confirmation, กันข้อมูลไม่ครบ, กัน review ที่ยังค้าง และเปิดใหม่หลัง reload
- ทดสอบเวลาเหตุการณ์ใหม่ เวลาเดิมที่ไม่ได้แก้ และเวลาที่แก้เองพร้อมหมายเหตุ
- สูตรคำนวณยาและเงื่อนไขยืนยันการบันทึกเดิมคงเดิม ตรวจเทียบไฟล์กับ V17.14.10
- การแก้เวลาใช้กับเหตุการณ์ใหม่ ไม่ได้แก้ไขย้อนหลังในข้อมูลเคสเก่า
