## Browser E2E limitation
The execution environment blocks normal `file://`, localhost, and synthetic HTTPS navigation by administrator policy. Therefore the visual checks above use Playwright `set_content()` with local assets inlined. This validates layout/CSS and isolated UI behavior, but is **not claimed as a full persistent-storage/PWA clinical E2E run**.
